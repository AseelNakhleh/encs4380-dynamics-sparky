# Module 4 – Guess the Sensor

**Course:** ENCS4380 – Interfacing Techniques  
**Project:** Dynamic Characteristics Interactive Toolkit

An interactive challenge where users guess sensor parameters from noisy response curves.

## Features

* Random first- and second-order sensors
* Step and sine response challenges
* Hints, score calculation, and actual-versus-guessed graphs
* Running score across rounds

## Run

Open `index.html` in a browser, or visit the team's GitHub Pages site and select Module 4.

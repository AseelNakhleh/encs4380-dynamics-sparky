Controller settings

First-order plant settings and model

G(s) = K/(τs + 1). Forward Euler advances the plant using dy/dt = (Ku − y)/τ. The PWM command u stays fixed between samples and ranges from 0 to 1 (0–100%).

The demo uses K = 1 and τ = 1 s. For a motor, express speed as a fraction of your chosen reference speed, then enter the gain in that same scale.

Digital PID equation and anti-windup

At sample k, e[k] = target − y[k]. The proportional term uses the current error. The integral term adds KiTse[k]. The derivative term is Kd(e[k] − e[k−1])/Ts. The initial previous error and integral term are zero.

With anti-windup enabled, the integral update is skipped when it would push the trial command past a PWM limit in the same direction. An update that helps pull the command back into range is allowed.
